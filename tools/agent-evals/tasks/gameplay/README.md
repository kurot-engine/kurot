# Gameplay tasks

Camera, tracking, collision, projectile, pooling, spawning, score, and win/loss
behavior.

Active: [Coin Lanes](coin-lanes.json), the complete Core-only game used by the
[documentation comparison](../../docs/documentation-comparison.md).

The extension adds [Asset Hunt](asset-hunt.json), [Tween Sprint](tween-sprint.json)
and [KUI Quiz](kui-quiz.json). Their executable acceptance is in `src/suite/`;
see the [protocol and current status](../../docs/gameplay-suite.md). Calibration
is complete; the planned five trials per task/arm have not all been run.
