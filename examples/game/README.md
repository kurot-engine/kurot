# Game example

The ordinary scene demonstrates resource loading, UI and tween animation.
The `?ui=1` route shows the default KUI skin kit, authored in
[DefaultUISkin.kui.xml](resource/ui/DefaultUISkin.kui.xml), with native Core/UI
rendering. Buttons, selected/disabled states, text input, ComboBox, TabBar,
sliders, progress, panel closing and hidden-bar list scrolling are interactive.

## Run the example

The lock installs registry Core 3.5.1, UI 5.2.2, Game 3.0.1, ui-document 0.14.0
and CLI 5.1.2. UI and Game resolve the same Core instance. Each example owns its
installation and lockfile independently. DefaultUI declares its Skin parts and uses
direct fields; onSkinRemoved releases its listeners before replacement.

Use Node.js 22.x (22.12.0 or later); `.nvmrc` selects Node 22. CLI 5 loads
TypeScript configs and relative helpers without a separate preloader.
For the ordinary scene, run from this directory:

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Open the printed URL with `?ui=1` for the gallery. The installed CLI preserves
constructor names for native Theme lookup; no checkout CLI or source binding is
needed. From this directory, strict one-shot builds use:

```sh
pnpm build --strict
pnpm release --strict
```

## Stage configuration

Main uses `createPlayer({ canvas })`. Configure stage dimensions, scale mode,
orientation and frame rate in `kurot.config.ts`; Core reads the canvas attributes
generated by the CLI. Explicit runtime options retain per-field priority.
During dev, save stage settings, wait for a successful update and manually
refresh the browser. No dev restart is needed for stage edits. Structural
configuration or imported configuration helper changes still require a restart.

## Ownership

Registry SDK versions remain controlled by this example's package.json and
lockfile. StyleManager loads licensed project fonts before starting the scene.
Default skins, color configuration and generated atlas assets are synchronized
from the CLI template by [the private asset tool](../../tools/default-ui-assets/README.md).
